## 更新机制

GitHub Actions 定时任务（`.github/workflows/update.yml`）：每天北京时间 15:10（UTC 07:10）拉取数据 → 计算指标 → 生成 HTML → 自动提交发布。生成失败时保持上一期页面不变。

数据源：天玑智能K线/风向罗盘（授权接口，密钥经 GitHub Secrets 注入）＋ 新浪财经公开行情接口。天玑罗盘数据滞后一个交易日，个别 05/09 合约腿当日无成交时以"数据至"列为准。
